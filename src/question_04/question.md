# 242. Valid Anagram

## Problem

Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`, and `false` otherwise.

An anagram means both strings contain the same characters with the same frequencies, but in different order.

---

## Example 1

### Input

```text id="a1b2c3"
s = "anagram"
t = "nagaram"
```

### Output

```text id="d4e5f6"
true
```

---

## Example 2

### Input

```text id="g7h8i9"
s = "rat"
t = "car"
```

### Output

```text id="j1k2l3"
false
```

---

## Constraints

- 1 <= s.length, t.length <= 5 \* 10^4
- `s` and `t` consist of lowercase English letters
