# Data Structures

## 🔷 Generics

---

## 📌 Definition

Java Generics is a programming concept that allows us to create **classes, interfaces, and methods that work with different data types while keeping type safety**.

Instead of writing separate logic for each data type, we write one reusable structure that works for all types.

---

## 🌍 Why We Use Generics

Generics are used to solve a very common problem:

👉 How can we write reusable code without losing type safety?

### Main reasons:

- Avoid code duplication
- Prevent runtime type errors
- Remove manual casting
- Improve code flexibility and readability
